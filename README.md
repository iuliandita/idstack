# idstack

Infra, DevOps, and SRE playbooks for coding agents, layered on top of [pstack](https://github.com/cursor/plugins/tree/main/pstack).

pstack gives agents a rigorous way to do software work. idstack adds the parts that infra work needs and app work doesn't: plan before apply, pin the target before touching it, prove backups restore, and never let a green check stand in for the live state.

Status: pre-alpha. Nothing is installable yet. See [docs/plan.md](docs/plan.md) for the design and roadmap, and [docs/playbooks.md](docs/playbooks.md) for the playbook catalog.
